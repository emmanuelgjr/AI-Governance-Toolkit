# Contributing

Especially valued:

- AI Governance leads with field experience submitting sector packs.
- ISO/IEC SC 42 participants reviewing clause mappings.
- Template improvements rooted in real deployments.
- Translations of AIIA questions into other languages.

## Local checks

```bash
npm ci
npm run test
npm run build
```

## Privacy is the headline feature

Any contribution that would require sending user data off-device is rejected.
The "all data in your browser" property is non-negotiable.
